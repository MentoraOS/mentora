# Diffs

Un Diff **constate une différence** entre deux états ; il ne crée
aucune autorité. Deux espèces :

- **Constitutional Diff** — différence entre deux Canonical Versions.
- **Vocabulary Diff** — différence de vocabulaire (termes réservés, scories).

> **Vide au Lot 1.** Le Vocabulary Diff purgera, à sa matérialisation, les
> scories relevées au Procès V — travail des lots ultérieurs, pas de celui-ci.
