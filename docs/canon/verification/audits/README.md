# Audits `.99`

Contenant des audits contradictoires : « détruire d'abord,
confirmer seulement si l'on échoue à détruire ». Un audit **atteste**, il ne
**fonde** ni ne **signe**.

> **Vide au Lot 1.** Emplacements réservés : F1.7.99, F2.x.99, F3.x.99,
> F4.x.99, F5.x.99, et le **Grand Audit F5.99** (Procès I → XII).
