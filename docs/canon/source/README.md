# Source

gelés. Tout le reste du corpus (vérification, projection, publication) en
dérive et ne peut jamais la contredire.

> 100 %** — la Source du Corpus Canonique est complète. Le Grand Audit F5.99
> clôt le Titre Production et l'ensemble F1 → F5 (une seule Constitution).
