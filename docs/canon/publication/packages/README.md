# Packages

Contenant des **packages** : assemblages documentaires d'une release, prêts à
distribuer. **Distribution Package** — les six Livres officiels :

| # | Livre | Contenu (références seules) |
|---|-------|------------------------------|
| 01 | [Foundation Book](01-foundation-book.md) | F1 + projection Foundation |
| 02 | [Constitution Book](02-constitution-book.md) | F2 + Glossaire + Vocabulary Diff |
| 03 | [Domain Book](03-domain-book.md) | F3 + Catalogues du domaine |
| 04 | [Application Book](04-application-book.md) | F4 + Handbook + Catalogues d'application |
| 05 | [Production Book](05-production-book.md) | F5 + Catalogues de production + Canon Release |
| 06 | [Projection Book](06-projection-book.md) | Glossaire, Vocabulary Diff, Handbook, Catalogues, Canon Release |

> Un Livre **n'a aucune autorité** (N°41) : il référence les chapitres
> propriétaires, il ne recopie jamais leur contenu (N°43). Ordre déterministe
> (N°44), identité documentaire (N°45).
