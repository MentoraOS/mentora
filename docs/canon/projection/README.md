# Projection

Une projection est une **dérivation déterministe de la Source**.
Elle n'est **jamais** une source de vérité : si elle diverge de la Source, la
Source a raison et la projection est **régénérée**.

- [`glossary/`](glossary/) — Glossaire Officiel bilingue.
- [`handbook/`](handbook/) — Handbook Officiel.
- [`catalogs/`](catalogs/) — Catalogues.
- [`indexes/`](indexes/) — Index dérivés.

> **Vide au Lot 1.** Ni le Glossaire ni le Handbook ne commencent à ce lot.
