# Décisions gouvernées

Deux familles de décisions tracées :

- [`adr/`](adr/) — **Architecture Decision Records** : une décision, ses
  alternatives, ses conséquences.
- [`rfc/`](rfc/) — **Requests for Comments** : une proposition soumise avant
  décision.

Une décision qui touche la **Source** passe par le **Titre VII**.
